# Blixto

Jogo de plataforma em uma tela, feito em HTML + Canvas, sem dependências.

Abra o `index.html` no navegador para jogar.

## Controles

- ← → (ou A / D): andar
- Shift: correr
- Espaço, ↑ ou W: pular
- ↓ (ou S): agachar
- R: recomeçar a fase
- M: ligar/desligar som

No celular aparecem botões na tela.

## Fase

Saia da corneta, pule buracos e escafandros, suba no transportador amarelo,
atravesse para a noite, pegue a estrela na janela e assista à dança.
